Official ReforgedZ

ReforgedZ is run by ReforgedZ, LLC. This page lists what is ours: four servers, the Workshop items we publish, and one Discord invite. Anything that is not on this page is not run by us, whatever it is called.

Four exact server names, nineteen Workshop IDs and one Discord invite. When in doubt, check what you see against this page.

02 Our Discord

The only invite we publish is discord.gg/reforgedz. Support, tickets, ban appeals and staff applications all go through it. We never send friend requests or direct messages asking you to join somewhere else.
