Finds characters whose Health hitzone is ≤ 0 (dead bodies) — directly, regardless of references. Living characters (Health > 0) and records with no health data are never listed or touched. Server must be STOPPED to purge; everything moves to a recoverable trash folder.
Prune accounts inactive for days:
Removes the character record of any account whose last login is older than N days — their account & stats stay, so a returning player just fresh-spawns a body. Accounts with no lastLogin are skipped. Everything moves to a recoverable trash folder. This directly shrinks the oversized gamemode save.
Copy DB from to
Copies the full persistence save (world DB + savepoints) from source to destination. The destination must be STOPPED — its current save is kept on the box as .save.pre-copy.<time>, so this is recoverable. The source can stay live (the copy runs a second delta pass to catch changes). A ~300 MB copy takes a few minutes; progress shows below and keeps running even if you close this page.
