Keybinds

The keys ReforgedZ adds, with its default keyboard and controller binding and the on-screen hint it shows.

On this page

Default bindings for the actions ReforgedZ adds to Arma Reforger. Vanilla controls are not listed. Controller inputs use Xbox button names. The hint column gives the text of the on-screen control hint, where the action has one.

Character

Action Hint Keyboard and mouse Controller
Autorun on or off Autorun Right Ctrl Hold RB, press X
Hold breath (aiming down sights with a weapon) Hold Breath Hold Left Shift Hold right stick click
Punch (empty hands) Left mouse button RT
Block Hold middle mouse button Hold LT
Tread water on or off (swimming with fins) Tread Water / Stop Treading X Left stick click

Items in hand

Action Hint Keyboard and mouse Controller
Eat or drink Consume Food/Drink R RT
Take a painkiller Take Painkiller R RT
Use a medkit Treat Yourself R RT
Cast, then reel in a fishing line Cast / Reel in Hold R Hold RT

Inventory

Action Keyboard and mouse Controller
Rotate item R Right stick click
Auto-sort storage T Left stick click
Split stack (dialog), or open a container Middle-click Menu
Split stack in half Hold middle mouse button Hold Menu
Drop item to ground G None

Build mode

Active while the building tool is in hand.

Action Hint Keyboard and mouse Controller
Open build mode Open Build Mode B RT
Build mode on or off V None
Piece menu Piece Menu B X
Place Place R RT
Rotate Rotate Mouse wheel RB + D-pad left or right
Rotate 90° Rotate 90 Left Shift + mouse wheel RB + D-pad left or right
Raise or lower Raise / Lower Left Ctrl + mouse wheel RB + D-pad up or down
Pitch Pitch (Up / Down) Home / End LB + D-pad up or down
Roll Roll (Left / Right) Insert / Delete LB + D-pad left or right
Snap on or off Snapmode : ON / Snapmode : OFF T Right stick click
Cancel or exit Cancel / Exit Build Right mouse button B

Placement

Codelocks, kits and plans being placed, and objects being moved.

Action Hint Keyboard and mouse Controller
Rotate Rotate Mouse wheel RB + D-pad left or right
Rotate 90° (kits and plans) Rotate 90 Left Shift + mouse wheel RB + D-pad left or right
Height Height (Ctrl+Wheel) Left Ctrl + mouse wheel RB + D-pad up or down
Place a codelock Place R RT
Place a moved object Place R X
Cancel a move Cancel Esc B

Trader menu

Action Keyboard Controller
Switch buy and sell T X
Buy or sell selected item (repeat to confirm) B Y
Search F View
Quantity down - LT
Quantity up = RT
Filter to ammo and attachments for carried weapons (ammo and attachment tabs) X Menu
Clear the sell list (sell mode) C Menu

Marketplace, crafting and salvage

Menu Action Keyboard Controller

Marketplace Price up E RB
Marketplace Select Enter A
Crafting Quantity down Z LT
Crafting Quantity up C RT
Crafting Confirm Hold Enter Hold A
Salvage station Amount down Z LT
Salvage station Amount up C RT

Lockpicking

Action Keyboard and mouse Controller
Aim the pick Mouse cursor position Left stick left or right (turns while held)
Apply pressure Hold F or left mouse button Hold RT
Fine aim None Hold LB
Cancel Esc B

Rebindable in the Controls settings

  • ReforgedZ: Autorun, Hold Breath, Tread Water
  • Building: Rotate Placement
  • Equipment: the use key for items in hand (R)
