Which Server Should I Join?

The four ReforgedZ servers, which map each one runs, and what is the same on all of them.

On this page
  • How to choose
  • The maps
  • The same on every server

Pick the region closest to you, then the map you want. There are four servers: Chernarus and Faircroft Islands each run on one server in Europe and one in North America.

Server In the server browser Region Map
EU1 [EU1] Official ReforgedZ Chernarus Europe Chernarus
EU2 [EU2] Official ReforgedZ Faircroft Europe Faircroft Islands
NA1 [NA1] Official ReforgedZ Chernarus North America Chernarus
NA2 [NA2] Official ReforgedZ Faircroft North America Faircroft Islands

How to choose

  1. Region first. EU servers are in Europe and NA servers are in North America. The nearer one gives you the lower ping.
  2. Then the map. Both maps run in both regions, so you never have to cross an ocean for the map you want.

The maps

Chernarus

Our own version of the Arma 2 map, reimagined for ReforgedZ by Bonzi and Soap. It is the only map with Rify, the wrecked cargo ship. Start with the Chernarus page.

Faircroft Islands

A small group of islands made by Lakes Dan, running the same ReforgedZ systems as Chernarus. Start with the Faircroft Islands page.

The same on every server

  • The same game. Food, water, body temperature, zombies, looting and bases work the same way on both maps.
  • The same restart times. Every server restarts at 00:00, 04:00, 08:00, 12:00, 16:00 and 20:00 UTC. See Server Restarts.
  • The same places to aim for. Both maps have a safe zone with traders, a black market, an offshore oil rig and an aircraft carrier. See The Safezone, The Black Market and The Oil Rigs.
  • The same contracts. The Broker in each safe zone offers the same kinds of daily and weekly work. See Contracts.
  • The same rules. See Server Rules.

Your character is not shared. Each server keeps its own character, gear and base, so starting on another one means starting from scratch there.
